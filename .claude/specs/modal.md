# Spec: Shared Modal Component

## 1. Контекст

На странице «Карта площадки» (секция `MapSection`) есть кнопка **«Как добраться»**. По нажатию на неё должно открываться модальное окно с информацией о транспорте (метро, автомобиль, автобусы/трамваи) — контент взят из макета Figma (node `11-493`, фрейм «Как добраться»).

Модалка нужна **переиспользуемая** — её должно быть можно открыть из любого места сайта, передавая произвольный контент. Поэтому компонент кладётся в `app/components/shared/`.

---

## 2. Принятые решения

### 2.1. Своя реализация vs библиотека

**Выбрано: своя реализация.**

Обоснование:
- Модалка простая: только контент, кнопка закрытия, оверлей. Никакого интерактива.
- В проекте уже есть прецедент — `CookieModal.vue` — самописная модалка на фиксированном позиционировании.
- Добавлять библиотеку (например, `@vueuse/core` ради `useDialog` или `headlessui`) — лишняя зависимость ради компонента в ~50 строк.
- Полный контроль над стилями, анимациями и доступностью.
- Проект минималистичный: 0 внешних UI-зависимостей, чистый Nuxt 3 + SCSS.

### 2.2. Управление состоянием (как открыть из любого места)

**Выбрано: композабл `useModal` с provide/inject.**

Альтернативы и почему нет:
| Подход | Вердикт |
|--------|---------|
| Передача коллбэка через props/события по цепочке | ❌ Неудобно, не «из любого места» |
| Pinia / Vuex | ❌ Тяжёлая зависимость для одного флага |
| EventBus (mitt) | ⚠️ Работает, но менее идиоматично во Vue 3 |
| **provide/inject + реактивный объект** | ✅ Идиоматично, легковесно, нативно |

Схема:
```
app.vue
  └─ ModalProvider   ← provide('modal', modalState)   ← место в DOM для <Modal />
       └─ любой компонент → const modal = inject('modal') → modal.open(content)
```

Для удобства это оборачивается в композабл:
- `useModal()` — получить объект с методами `open(options)` / `close()` и реактивным `isOpen`.
- По умолчанию `open()` принимает `{ title, content }` (content — HTML-строка, пропущенная через `v-html` с санитайзом).

### 2.3. Структура данных

Данные для модалки «Как добраться» кладём в `data/modal.json` (на уровне `data/`, не `data/sections/`, потому что это не секция, а общие данные для модалки). Структура — массив, чтобы можно было добавлять другие модалки в будущем:

## 4. API компонента Modal

### Props

| Prop | Тип | По умолчанию | Описание |
|------|-----|-------------|----------|
| — | — | — | Управляется через `useModal()`, props не нужны |

### Slots / Content

Модалка принимает контент через `useModal().open({ ... })`:

```ts
interface ModalOptions {
  title: string          // заголовок (например «как добраться»)
  sections?: ModalSection[]  // секции с иконками
}

interface ModalSection {
  icon: string    // имя иконки (без пути/расширения), например "directions_subway"
  title: string   // заголовок секции («На метро»)
  text: string    // текст (поддерживает <br>)
}
```

### Поведение

1. **Открытие**: вызов `modal.open(options)` → устанавливает `isOpen = true`, сохраняет переданный контент.
2. **Закрытие**:
   - По клику на крестик (×) в правом верхнем углу.
   - По клику на тёмный фон (оверлей) позади модалки.
   - По нажатию клавиши `Escape`.
3. **Блокировка скролла**: при открытии вешается `overflow: hidden` на `<body>`, при закрытии убирается.
4. **Анимация**: плавное появление/исчезновение через Vue `<Transition>` (fade + лёгкий scale).
5. **Доступность**: `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, фокус-ловушка (первый фокус на кнопку закрытия, при закрытии фокус возвращается на кнопку-триггер).

## 5. Стилизация (SCSS)

Модалка наследует визуальный стиль макета Figma:

- **Оверлей**: `background: rgba(0, 0, 0, 0.5)` — тёмный полупрозрачный.
- **Карточка модалки**: фон `$blue` (#202F3C), скругление 13px, отступы внутри ~3–4rem.
- **Заголовок**: `$unbounded`, 42px, цвет `$light`, uppercase (как на макете).
- **Адрес**: `$tektur`, 14px, цвет `$white`, справа вверху (или под заголовком — адаптируем под мобильные).
- **Кнопка закрытия (крестик)**: красный крестик в углу, как в `CookieModal`.
- **Секции с иконками**: каждая секция — иконка 24×24 слева, заголовок `$tektur bold`, 18px, цвет `$red`, текст `$tektur regular`, 14px, цвет `$white`.
- **Адаптив**: на `$mobile` уменьшаем заголовок, отступы, ширину модалки (max-width: 90vw).

### Ширина модалки

- Десктоп: max-width ~760px (как карточка на макете).
- Планшет: max-width ~90vw.
- Мобильный: max-width ~95vw.
