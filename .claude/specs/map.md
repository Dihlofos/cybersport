# MapSection — Клик по элементам карты

## Контекст

Компонент `MapSection.vue` рендерит карту площадки с SVG-элементами (`id="figure 1"` … `id="figure 19"`) и легенду (`zones` + `stations`). Сейчас элементы карты не интерактивны.

## Что нужно сделать

### 1. Кликабельность SVG-элементов

Все элементы с `id`, начинающимся на `figure`, должны реагировать на клик.

### 2. Поведение при клике на элемент

При клике на `<g id="figure N">`:

1. **Сам SVG-элемент** — добавление CSS-класса `map__figure--active`, который:
   - Меняет `fill` у `<rect>` на красный (`$red`)
   - Меняет `fill` у `<text class="map__figure">` на белый (`$light`)
   - При повторном клике на тот же элемент — снимает класс (деактивация)
   - При клике на другой элемент — предыдущий деактивируется, новый активируется

2. **Плашка с описанием** — появляется рядом с элементом:
   - Белый фон, скруглённые углы, тень
   - Текст: название зоны/станции (из данных легенды)
   - Кнопка «×» (крестик) для закрытия
   - При закрытии — плашка исчезает, класс `map__figure--active` снимается
   - При клике вне плашки — плашка закрывается, класс снимается

3. **Легенда** — соответствующий `<li class="map__legend-item">` получает класс `active`:
   - Стили на `.active` уже написаны в SCSS (номер и название становятся красными, у названия появляется стрелка `→`)
   - При деактивации — класс `active` убирается

### 3. Генерация плашки в DOM

Плашка **одна** на весь компонент, рендерится внутри `.map__map-area`. При клике на элемент она позиционируется рядом с ним. При закрытии — скрывается, а не удаляется из DOM.

### 4. Позиционирование плашки

Нужна библиотека для расчёта позиции плашки относительно SVG-элемента, чтобы она:
- Не вылезала за границы `.map__map-area`
- Автоматически выбирала сторону (сверху/снизу/слева/справа) в зависимости от доступного места

**Предложение:** использовать [Floating UI](https://floating-ui.com/) (`@floating-ui/vue`) — это современный наследник Popper.js, лёгкий (≈2 KB gzip), с первоклассной поддержкой Vue 3 / Nuxt 3.

Альтернатива: написать позиционирование вручную, но Floating UI даст готовые `autoPlacement`, `shift` (чтобы не вылезало за границы), `offset` и пр.

### 5. Данные для плашки

Текст для плашки берётся из объединённого списка `zones` + `stations` по номеру. Структура данных уже есть в `map.json`:
```json
{
  "zones": [
    { "number": 1, "name": "Зона регистрации и выдачи призов" },
    ...
  ],
  "stations": [
    { "number": 5, "name": "CS2" },
    ...
  ]
}
```

Нужно смержить `zones` и `stations` в один маппинг `number → name`.

### 6. Состояния

| Состояние | Описание |
|-----------|----------|
| **idle** | Ничего не выбрано |
| **active** | Выбран элемент N: плашка открыта, legend__item активен, figure подсвечен |
| **closing** | Пользователь кликнул на крестик / вне плашки → возврат в idle |

### 7. CSS-классы (написать в SCSS)

- `.map__figure--active` — на `<g>` элемент SVG
- `.map__tooltip` — плашка
- `.map__tooltip-close` — кнопка закрытия
- `.map__figure--active rect { fill: $red; }` — заливка прямоугольника
- `.map__figure--active .map__figure { fill: $light; }` — белый текст номера

### 8. Что уже есть

- Стили для `.active` на `legend__item` уже написаны (`.active &` внутри `&__legend-num` и `&__legend-name`)
- Все SVG-элементы уже имеют `id="figure N"`
- Данные уже в `map.json`

## План реализации

1. Добавить `@floating-ui/vue` (или `@floating-ui/dom`) в зависимости
2. Добавить реактивное состояние в `<script setup>`: `activeFigure` (number | null)
3. Повесить `@click` на каждый `<g>` с id `figure *`
4. Добавить computed для получения имени по номеру
5. Добавить одну плашку в DOM внутри `.map__map-area`
6. Написать логику позиционирования через Floating UI
7. Написать SCSS для плашки и активного состояния фигур
8. Связать клик с активацией legend__item

## Ответы на вопросы

1. **Библиотека позиционирования:** ✅ Floating UI (`@floating-ui/vue`)
2. **Поведение при клике на другую фигуру:** ✅ плашка всегда одна на экране, переезжает к новому элементу
3. **Клик по тому же элементу повторно:** ✅ деактивация (закрытие плашки)
4. **Анимация:** ❌ не нужна
